# 프렙 카페 운영 관리 프로그램 PRD

## 사용 목적

매장 운영자가 판매·비용·실사 재고를 기록하고, 월별 메뉴 수익성과 손익, 재료의 마지막 실사 수량을 확인한다. 처음 만들 최소 기능(MVP)은 총 4시간 실습 안에 판매 기록 입력부터 결과 확인까지 이어지는 흐름을 제공한다.

## 자료의 종류·기간·단위·중복 주의사항

### 자료에서 확인한 사실

- 샘플은 가상 매장 ‘프렙 카페’의 기록이다. 공급사 3곳, 재료 11종, 메뉴 8종, 레시피 22건, 재료 가격 이력 33건이 있다.
- 영업 달력은 457일, 판매 기록은 6,112건, 초기 재고는 11건, 재고 변동은 1,515건이다. 월별 비용 계획은 120건, 날짜별 비용 기록은 3,560건이다.
- 기록 기간은 2025-07-01부터 2026-09-18까지다. 달력은 2026-09-30까지 있지만, 9월 19일 이후는 미마감이다. 연간 합계도 일부 기간만 포함한다.
- 판매 한 건은 주문 한 건이 아니라 일자·메뉴·판매채널별 수량 집계다. 샘플의 판매 ID와 이 조합에는 중복이 없다.
- 금액은 원화·부가세 제외, 재료 수량은 g·ml·개다. 구매 가격은 포장 단위이고 레시피 수량은 메뉴 한 개 기준이다.
- 실사 수량이 기록된 재고 변동은 24건이며 재료 11종 중 2종에 해당한다. 나머지는 실사 기록이 없을 수 있다.
- 각 재료의 샘플상 최신 가격은 2026-09-01 적용 가격이다.

### 기획 시 주의사항

- 엑셀과 JSON은 같은 자료이므로 함께 더하지 않는다.
- 월별 비용 계획과 날짜별 비용 기록은 같은 비용을 다른 단위로 표현한다. 실제 손익에는 계획 금액을 추가하지 않는다.
- 빈칸은 0과 다를 수 있다. 실사 기록이 없는 재료를 재고 0으로 처리하지 않는다.
- 사용자가 선택한 기준에 따라 메뉴 수익성과 월별 손익은 과거 판매도 현재 레시피·가격으로 재산정한다. 따라서 과거 결과가 바뀔 수 있고, 당시 실제 원가를 반영한 손익과 다를 수 있다.

## 사용자와 사용 순서

- **주 사용자 제안:** 매장 운영자. 직원별 계정이나 권한이 필요한지는 미정이다.
- 사용 순서: 샘플 자료를 바탕으로 시작 → 판매·비용 기록 입력 또는 수정·삭제 → 재료별 실제 수량과 실사일 입력 → 마감된 달의 메뉴 수익성 확인 → 같은 달의 재산정 손익과 마지막 실사 수량 확인

## 필수 기능

### 수업 중 구현할 MVP

- 샘플 자료를 시작 자료로 사용한다.
- 판매·비용 기록을 직접 입력·수정·삭제한다.
- 재료별 실제 실사 수량과 실사일을 기록하고, 마지막으로 기록된 실사값을 확인한다.
- 월별 메뉴 수익성과 손익을 확인한다. 마감된 달만 표시하며, 미마감된 달은 결과에 포함하지 않는다.
- 메뉴 수익성과 손익은 최신 레시피·가격 기준으로 재산정한다. 월별 손익에는 기록된 매출·결제 수수료·날짜별 비용을 반영하고, 월별 비용 계획은 더하지 않는다.
- 기록을 저장하고, 잘못되거나 빠진 값은 확인할 수 있게 한다.

### 수업 후 확장할 기능

- 엑셀 양식 내려받기와 판매·비용 자료 가져오기
- 일·주·분기·반기·연간 조회
- 재료 입고·폐기 기록과 발주량 참고
- 예상 손익
- 백업·복원

## 제외 기능

- 수업 중에는 엑셀 가져오기, 월 이외 기간 조회, 입고·폐기 기록, 발주량 참고, 예상 손익, 백업·복원을 구현하지 않는다.
- 이번 PRD에서는 계산식, 화면 디자인, 기술 선택, 상세 동작, 코드를 정하지 않는다.

## 완료 기준

- 판매·비용 기록을 입력·수정·삭제하고, 재료 실사 수량을 기록한 뒤 월별 결과를 확인할 수 있다.
- 저장 후 다시 열어도 변경 내용이 남고, 입력한 변경·삭제가 관련 결과에 반영된다.
- 마감된 달만 결과에 포함되며, 비용 계획이 날짜별 비용에 중복 합산되지 않는다.
- 과거 기록을 현재 가격으로 재산정하는 기준이 메뉴 수익성과 월별 손익에 일관되게 적용된다.
- 실사 기록이 없는 재료는 0이 아니라 “실사 기록 없음”으로 구분된다.
- 대표 메뉴·월·재료의 결과를 자료와 대조해 검증하고, 누락·잘못된 입력이 조용히 저장되거나 결과를 왜곡하지 않는다.
- 배포된 프로그램에서 위 흐름을 처음부터 끝까지 수행할 수 있다.

## 미정 사항

- 예상 손익의 기준과 기간
- 주·분기·반기·연간 기간의 경계 기준
- 입고·폐기·발주량을 계산할 때 사용할 재고 기준
- 엑셀 열 구성과 중복 자료를 가져올 때의 처리 기준
- 백업 파일 형식과 복원 시 기존 자료 처리 방식
- 샘플의 최신 가격 이후 가격을 갱신하는 방법. 샘플 가격은 2026-09-01 적용분까지다.
- 사용자 수, 계정·권한, 여러 기기에서의 자료 공유 필요 여부
