# 프렙 카페 운영 관리

문서와 디자인 시안의 MVP 기능을 실행할 수 있는 로컬 웹 앱입니다. 가상 샘플을 SQLite로 한 번 가져온 뒤, 운영자 계정으로 로그인해 판매·실사 자료와 월별 분석을 확인합니다.

## 시작하기

- Node.js 22.13 이상을 준비합니다. 외부 npm 패키지는 필요하지 않습니다.
- 프로젝트 폴더에서 `npm start`를 실행합니다.
- 브라우저에서 `http://127.0.0.1:4173`을 엽니다.
- 첫 화면에서 운영자 이름·이메일·8자 이상 비밀번호를 등록합니다. 다음 실행부터 같은 정보로 로그인합니다.

앱은 `data/prep-cafe.sqlite`에 샘플과 입력 기록을 저장합니다. 이 파일을 지우면 앱 시작 시 원본 가상 JSON 샘플부터 다시 적재됩니다. 앱은 로컬 컴퓨터에서만 접속할 수 있도록 `127.0.0.1`에 바인딩합니다.

## 제공 기능

- 운영자 1인 계정 생성, 로그인·로그아웃, 로그인 세션 확인
- 판매 집계 입력·수정·삭제, 중복 집계 확인, 페이지 탐색·검색
- 재료별 실제 실사 수량과 마지막 실사일 저장
- 날짜별 실제 비용 조회
- 모든 날짜가 마감된 달만 선택, 현재 재료 가격·레시피 기준 메뉴 수익성과 월 손익 재산정
- 입력값 검증과 저장 후 재조회

비용 내역 CRUD, 외부 DB 연결, 원격 배포는 이 로컬 구현에 포함하지 않았습니다. TRD의 Supabase/Vercel 구성을 사용하려면 사용자 소유 서비스 프로젝트와 자격 정보가 필요합니다. 현재 앱은 로컬 사용 계정과 SQLite를 사용하며 공개 배포용 인증·데이터 보호 구성을 대신하지 않습니다.
